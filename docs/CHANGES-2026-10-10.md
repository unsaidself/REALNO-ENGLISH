# Обновление zhekandus

## Исправления

- Escape и нажатие вне редактора спрашивают перед выходом. Редактор и быстрое добавление сохраняют черновик для восстановления после перезагрузки.
- Общий разбор массовой вставки и файлов: таб Quizlet, CSV, BOM, шапка, кавычки и многострочные поля. Для дефиса есть отдельный режим, для неоднозначных разделителей — выбор первого/последнего и предпросмотр.
- Дубликаты требуют явного решения: пропустить либо сохранить. Термины со знаком «;» больше не режутся молча.
- «Трудно» получает клавишу 4. Пробел, 1/2/3 и варианты теста 1–4 сохранены.
- Пустая категория не оставляет лишнюю точку. Причина недоступности пропусков показана на кнопке режима.
- Нижняя навигация телефона остаётся видимой и имеет подписи. Основные кнопки и иконки имеют зоны нажатия не меньше 44 px. На главной одна кнопка создания набора.
- Открытие большого набора больше не строит упражнения с пропусками для всех карточек. Варианты теста используют индекс ответов.
- Ссылка аварийного загрузчика указывает на закреплённую проверенную версию, а не исчезающую ветку. Обработка повреждения Base64/gzip и лицензионный комментарий сохранены.

## Новые функции

1. Быстрое добавление из шапки в последний набор.
2. Фильм/сериал, сезон-серия, таймкод и фильтр по источнику.
3. Веб-сборка PWA: manifest, иконки и service worker с офлайн-кэшем.
4. Вставка из Quizlet с выбором разделителя и предпросмотром.
5. Автокопия в отдельный JSON-файл с прогрессом и вложениями. Для переноса между устройствами используется резервная копия версии 1.
6. Ручная звёздочка, режим по звёздочкам и исправление карточки из занятия с сохранением ID, прогресса и вложений.
7. Встроенная офлайн-озвучка US/UK и озвучка примера. Недостающий британский голос добавлен из закреплённой версии eSpeak.
8. Дневной лимит новых карточек, напоминание внутри открытого приложения, подтверждение выхода из занятия и отмена удаления в течение суток.
9. TXT-экспорт для Anki с примером, источником и тегом сложной карточки. Удалённый ранее импорт .apkg не возвращён.

## Ограничения браузеров

- Обычный HTML работает без сервера. PWA устанавливается из веб-сборки, размещённой на HTTPS. В архиве есть отдельная папка `web`; сайт автоматически не развёрнут.
- Автокопия требует File System Access API. Выбранный файл обновляется, пока страница открыта; после перезагрузки или закрытия его нужно выбрать снова. В неподдерживаемом браузере остаётся ручное скачивание копии.
- Очистка браузерного хранилища удаляет локальные данные и кэш. Отдельный файл копии нужен и при установке PWA. Серверной синхронизации нет.
- Закрытый браузер не обеспечивает гарантированные офлайн-напоминания. При запрете системных уведомлений напоминание показывается внутри приложения.
- Запись произношения хранится в текущем упражнении: её можно скачать. Перед выходом или переходом к следующему слову приложение предупреждает.
- Лицензия GPLv3, исходники приложения и уведомления сторонних компонентов включены в архив. Оригинальные исходники и ревизия движка указаны в `src/voice/NOTICE`.

## Проверки

Автоматические тесты проверяют IndexedDB и миграцию, ошибки квоты, резервные копии версии 1 с вложениями, CSV/Anki, разбор вставки, расписание повторений, письменные ответы, статистику, ранги и лимит новых карточек.

Итог: 76 автоматических тестов пройдены; стандартный `npm test` также завершён успешно. Сборка и генерация самостоятельного HTML выполнены. 12 проверок загрузчика и 5 проверок повреждения реального файла подтверждают понятную ошибку, сохранение прежних данных и отсутствие записи в хранилище при неудачном запуске. Самостоятельный HTML проверен через `file://` без сети, системных голосов и WebAssembly; английская и русская озвучка работают. На проверочном наборе из 3000 карточек открытие заняло около 0,20 с, запуск теста — 0,74 с в этой среде; это не обещание скорости на любом телефоне.

Проверки в Chromium подтверждают сохранность прежней коллекции и байтов вложений, восстановление черновиков, работу предупреждений и дубликатов, источников, звёздочек, отмены удаления, клавиатуры и мобильной навигации на ширине 320–750 px. Отдельно проверены реальные файловые записи автокопии, сохранение предыдущей копии при ошибке записи, звуковые данные US/UK и офлайн-перезагрузка PWA. Реальные iPhone/Safari и Android в этой среде не проверялись.


## Обновление озвучки

Онлайн-голоса больше не отбрасываются по localService. Добавлены выбор и
индивидуальная проверка всех английских голосов, рейтинг качества после
совпадения языка/акцента, ожидание онлайн-старта до 6 секунд и диагностика
реального источника. eSpeak остаётся последним запасным голосом и показывает
инструкцию для установки лучшего голоса.

Добавлены необязательный «Живой голос» OpenAI/Google Cloud/Azure и Piper WASM
с моделями US/UK, скачиваемыми один раз в IndexedDB. Аудиокэш прикрепляется к
карточке и сохраняется в копии версии 1; ключи хранятся отдельно и не попадают
в копии. Старый загрузчик и первоначальный комментарий eSpeak GPLv3 сохранены.
Полные функции и доказательства проверки: SPEECH-FUNCTIONS.md и SPEECH-CHECKS.md.
