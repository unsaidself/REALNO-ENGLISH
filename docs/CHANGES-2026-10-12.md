# Случайные вопросы и удаление рангов — 12 октября 2026

## Исправление окна серии

- Полностью удалены всплывающее окно винстрика, конфетти и его таймер на
  2,6 секунды. При переходе к следующему вопросу ничего не остаётся поверх
  занятия. Нет автоматического окна после каждого третьего ответа.
- Серия показана небольшим индикатором внутри занятия. 1–2 ответа — зелёный,
  3–5 — синий, 6–8 — янтарный, 9 и больше — коралловый. Для тёмной темы
  используются светлые оттенки; цвет сопровождается числом ответов.
- В игре на пары такой же индикатор обновляется после правильной пары
  или ошибки. При выходе он исчезает вместе с содержимым занятия.
- Убраны прыжки и вращение значка серии. Сохранены доступная подпись
  `aria-live="polite"` и поддержка уменьшения анимаций.
- Проверено в Chromium: отсутствие окна при 3/6/9 правильных ответах и
  немедленной смене вопроса; четыре цвета; сброс серии после ошибки;
  автоматический переход в карточках; запоминание, пропуски и пары.
  Проверки прошли в светлой и тёмной теме, включая ширину 375 px.
- 74 существующих теста прошли без пропусков. В браузере по 26 ответов
  в каждой теме: прогресс и исходные ID сохраняются после перезагрузки,
  ошибок JavaScript и сетевых запросов офлайн не было.

## Что изменилось

- При каждом запуске перемешивается очередь теста, карточек, запоминания,
  пропусков, повторения, слабых карточек и занятий по звёздочкам. В игре
  «Найди пару» перемешиваются выбор карточек и обе колонки.
- Общий запуск перемешивает подходящие карточки до применения дневного
  лимита. Новые карточки больше не выбираются только из начала набора.
  Для пропусков сначала выбираются карточки с подходящим примером.
- Повторение выбирает только карточки, доступные по расписанию, и новые
  карточки в рамках дневного лимита; порядок внутри занятия случайный.
  Слабые карточки по-прежнему выбираются по точности, затем перемешиваются.
- Для теста сохранён случайный порядок вариантов ответа. Ошибки в обучении
  возвращаются в конец очереди для повторной попытки, как раньше.
- Перемешивание создаёт новую очередь и не переставляет карточки в наборе:
  порядок редактора и экспорта, стабильные ID и вложения сохраняются.
- Удалены раздел и модуль рангов, XP, начисление опыта, уведомления о
  повышении, надписи в занятиях и все стили рангов. Нижняя навигация телефона
  содержит пять разделов. Ранг больше не создаётся для нового профиля.
- Сохранены статистика, ежедневная цель, серии ответов и расписание
  повторений. Необязательные поля старых копий остаются совместимыми;
  прежний объект ранга не используется и не меняется при ответах.
- Аудио остаётся полностью отключённым, движков и аудио API нет.

## Проверки

- `npm test -- --test-isolation=none --test-reporter=spec`: 74 теста, все
  успешные, без пропусков. В этой облачной среде режим без изоляции позволяет
  отчёту перечислить реальные проверки внутри каждого файла.
- Новые проверки охватывают все перестановки трёх карточек, отсутствие
  изменения исходных карточек и ID, случайный выбор перед дневным лимитом,
  новые очереди, ограничения расписания/точности, пропуски и пустую очередь.
- Проверки сброса и удаления подтверждают сохранность наборов, вложений,
  настроек и необязательных полей; новый профиль не получает объект ранга.
- `npm run build` и `npm run standalone`: успешная веб-сборка и один HTML
  с gzip/Base64-загрузчиком. Первый исторический комментарий eSpeak GPLv3
  сохранён. Размер HTML — около 161 КБ.
- В настоящем Chromium без сети каждый из семи последовательных режимов
  запущен семь раз: стартовые карточки меняются. Пять новых игр на пары
  выбирают и располагают карточки по-разному.
- Два полных теста по 12 вопросов: каждый содержит все карточки ровно один
  раз, порядок различается, ответы цифрами работают и результат 12/12.
- Проверены «Я был прав», оценка клавишей 2, переворот Пробелом и правка
  перевёрнутой карточки. Счётчики ответов, правильных ответов и расписание
  сохраняются без начисления XP. Исходный порядок набора и ID не меняются.
- JSON-копия версии 1 сохраняет прогресс и необязательные поля. Перезагрузка
  сохраняет набор, имя и результаты; свежий профиль не показывает ранги.
- При ширине 375 px пять подписанных вкладок, тёмная тема и уменьшение
  анимаций работают без горизонтального выхода за экран.
- Веб-сборка: manifest, service worker, навигация и повторный запуск
  карточек офлайн; ошибок JavaScript и внешних запросов не было.

Проверен Chromium с размером экрана телефона. Физические телефоны и другие
браузеры в этой среде не проверялись. Веб-сайт автоматически не развёрнут.

## Обновление

Сначала скачай JSON-копию в «Копиях и импорте», затем открой новый HTML.
При смене браузера или адреса файла восстанови копию вручную: личные данные
хранятся в браузере, а не внутри программы. Копии версии 1 совместимы.
Для установленной PWA замени все файлы папки `web` на прежнем HTTPS-сайте
и перезагрузи приложение после загрузки новой сборки в кэш.
