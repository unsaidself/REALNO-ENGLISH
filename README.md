# zhekandus

Локальное приложение для карточек, тестов и английского. Профиль: `leverage100x`.

Готовая версия: скачай [zhekandus.zip](./zhekandus.zip), распакуй архив и открой `zhekandus.html` в актуальном браузере. Установка и сервер не нужны. Архив содержит приложение со всеми функциями и встроенной английской и русской озвучкой; размер около 1,1 МБ.

## Запуск

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run standalone
```

`dist/zhekandus.html` — самостоятельный сжатый файл, текущая сборка около 1,5 МБ: скачай его и открой в актуальной версии Chrome, Edge, Firefox или Safari. Браузер распаковывает код самостоятельно; сервер и интернет для занятий, встроенной озвучки, импорта и резервных копий не нужны.

## Возможности

- Пользовательские категории и наборы, карточки с переворотом, запоминание, тесты в обоих направлениях, интервальное повторение и игра на сопоставление.
- Пропуски из собственных примеров использования и аудирование с письменным ответом. Для пропусков добавь предложение, содержащее слово или выражение, в разделе вложений набора.
- Озвучка голосом устройства с автоматическим переходом на встроенный eSpeak при отсутствии или сбое голоса. Полные английские и русские данные включены в файл. В настройках можно выбрать встроенный голос и скорость.
- Произношение: образец, локальная запись до 30 секунд, загрузка своего аудио, последовательное сравнение и скачивание записи. Сравнение самостоятельное; автоматическая оценка не рассчитывается. Микрофон запрашивается после нажатия «Записать»; при отказе можно загрузить аудиофайл. Запись сохраняется в текущем упражнении, а для постоянного хранения её нужно скачать.
- Отдельная страница рангов: Бронза, Серебро, Золото, Платина, Алмаз и Мастер. Правильный ответ приносит 10 XP, до трёх начислений на карточку за локальный день. Прежние правильные ответы тоже учтены.
- «Копии и импорт»: JSON-копия всех наборов, прогресса, рангов, настроек и двоичных вложений; проверка файла и предварительный просмотр перед восстановлением. Восстановление заменяет текущую коллекцию и прогресс. При ошибке сохранения текущие данные сохраняются.
- Импорт CSV с запятыми, точкой с запятой или табуляцией; заголовки, кавычки, переносы внутри полей и UTF-8 BOM. Необязательные поля: example, category, title. Поддерживается текстовый экспорт Anki и архивы `.apkg` с SQLite и вложениями, включая современный Zstandard-формат.
- Дневные цели, календарь, темы и акцентные цвета, звуковая обратная связь и анимации.

Карточки и прогресс хранятся в localStorage (`lexi-data`), файлы — в IndexedDB (`zhekandus-media`). Данные привязаны к браузеру и его профилю. Используй локальные резервные копии для переноса между устройствами и браузерами. Приложение не отправляет карточки и записи на сервер.

## Локальный голос

Движок speak.js на основе eSpeak и данные включены в исходники. Для воспроизведения файлов из закреплённой версии исходников:

```sh
node scripts/prepare-speech.mjs
```

eSpeak распространяется по GPL-3.0. Лицензия, ссылки на исходники и описание адаптации находятся в `src/voice/LICENSE` и `src/voice/NOTICE` и включаются в HTML-файл. Синтез работает в отдельном Web Worker и не блокирует интерфейс. Вместо большого движка со всеми языками используются компактный движок и полные данные двух языков; текст для русского преобразуется в UTF-8.
