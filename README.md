# zhekandus

Офлайн-приложение для карточек, тестов и интервального повторения. Интерфейс на русском, ванильный JavaScript, без бэкенда. Имя в профиле можно изменить в настройках; по умолчанию — «Ученик», аватар — первая буква имени.

Готовая версия: скачай [zhekandus.zip](./zhekandus.zip), распакуй архив и открой `zhekandus.html` в актуальном браузере. Также доступен [готовый HTML](./zhekandus.html). Установка и сервер не нужны. Английская и русская озвучка включены в приложение.

## Запуск

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run standalone
```

`dist/zhekandus.html` — самостоятельный HTML-файл со сжатым кодом и встроенными ресурсами. Открой его в актуальной версии Chrome, Edge, Firefox или Safari. Браузер распаковывает код самостоятельно; сервер и интернет для занятий, встроенной озвучки, импорта и резервных копий не нужны.

## Возможности

- Пользовательские категории и наборы. При первом запуске коллекция пустая: можно создать набор или импортировать карточки. Демо-наборы и готовые категории не добавляются.
- Редактор с отдельными полями термина и определения, добавлением, удалением и перемещением карточек. Есть массовая вставка текста. У каждой карточки стабильный идентификатор: переименование и изменение порядка сохраняют её прогресс, изображения и аудио.
- Карточки с переворотом, запоминание, тесты с вариантами ответа в обоих направлениях, интервальное повторение и игра на сопоставление. «Продолжить» открывает повторение, если есть карточки на сегодня, иначе последний изученный набор.
- Четыре оценки в карточках и повторении: «Ещё повторить» снижает уровень на два, до минимального уровня; «Трудно» оставляет уровень; «Знаю» повышает на один; «Легко» — на два. Интервалы: 1, 3, 7, 14, 30 и 90 дней; после ошибки карточка возвращается через 10 минут.
- Письменные ответы принимают варианты через `/`, игнорируют ведущее `to` и пояснения в скобках. Для ответов длиннее пяти символов допускается одна опечатка: вставка, удаление или замена символа. После ошибки кнопка «Я был прав» исправляет результат без повторного учёта ответа.
- «Слабые карточки»: до 20 уже изучавшихся карточек с самой низкой долей правильных ответов. По каждой карточке сохраняются число ответов и число ошибок. В статистике отдельно показаны правильные ответы и выученные карточки с уровнем повторения 4 и выше.
- Поиск по названию и описанию набора, терминам и определениям карточек. Удаление набора и сброс прогресса требуют подтверждения. Сброс отдельного набора очищает его интервалы и статистику карточек, сохраняя общую историю ответов и XP. Общий сброс очищает учебный прогресс, сохраняя наборы, вложения и настройки.
- Пропуски из собственных примеров использования и аудирование с письменным ответом. Для пропусков добавь предложение, содержащее слово или выражение, в разделе вложений набора.
- Озвучка всеми доступными голосами браузера, включая Microsoft Natural и Google. Настройки показывают название и тип реально использованного голоса. Есть выбор голоса, облачный TTS с локальным аудиокэшем и скачиваемый нейросетевой Piper для работы без сети; встроенный eSpeak остаётся последним запасным вариантом.
- Произношение: образец, локальная запись до 30 секунд, загрузка своего аудио, последовательное сравнение и скачивание записи. Сравнение самостоятельное; автоматическая оценка не рассчитывается. Микрофон запрашивается после нажатия «Записать»; при отказе можно загрузить аудиофайл. Запись сохраняется в текущем упражнении, а для постоянного хранения её нужно скачать.
- Отдельная страница рангов: Бронза, Серебро, Золото, Платина, Алмаз и Мастер. Правильный ответ приносит 10 XP, до трёх начислений на карточку за локальный день. Прежние правильные ответы тоже учтены.
- «Копии и импорт»: JSON-копия всех наборов, прогресса, рангов, настроек и двоичных вложений; проверка файла и предварительный просмотр перед восстановлением. Формат `zhekandus-backup`, версия 1, сохраняет совместимость с прежними копиями; новые поля необязательны. Восстановление заменяет текущую коллекцию и прогресс. При ошибке сохранения текущие данные сохраняются. Если с последней копии прошло больше семи дней, на главной появляется напоминание.
- Импорт CSV с запятыми, точкой с запятой или табуляцией; заголовки, кавычки, переносы внутри полей и UTF-8 BOM. Необязательные поля: пример, категория и набор (`example`, `category`, `title`). Поддерживается текстовый экспорт Anki в TXT/TSV. Импорт архивов `.apkg` удалён вместе с SQLite и Zstandard.
- Экспорт CSV с колонками `термин`, `определение`, `пример`, `категория`, `набор`. Файл можно снова импортировать в приложение; прогресс и двоичные вложения переносятся через JSON-копию.
- Дневные цели, календарь, светлая и тёмная темы, акцентные цвета, звуковая обратная связь и анимации. Изменения настроек сохраняются сразу. Интерфейс поддерживает клавиатуру, удержание фокуса в модальных окнах и уменьшение анимаций по системной настройке.

### Горячие клавиши

В «Карточках» и «Повторить»: `Пробел` — перевернуть, `1` — «Ещё повторить», `2` — «Знаю», `3` — «Легко». Оценку «Трудно» можно выбрать кнопкой. В тесте `1`–`4` выбирают вариант ответа. Подсказки доступны на экране упражнения.

## Хранение данных

Наборы, прогресс, настройки и файлы хранятся в IndexedDB (`zhekandus-media`, версия схемы 2). Данные прежней версии из localStorage (`lexi-data`) переносятся при запуске; старый ключ удаляется только после успешного завершения записи. Существующие вложения остаются в базе. Сохранение объединяет частые изменения с задержкой около 300 мс и запускается при уходе со страницы. Ошибка квоты показывается отдельно, с возможностью повторить сохранение и сделать резервную копию.

При первом сохранении приложение запрашивает у браузера постоянное хранение через `navigator.storage.persist()`. Решение принимает браузер. Данные привязаны к браузеру и его профилю; локальные резервные копии нужны для переноса между устройствами и браузерами. При удалении набора удаляются его вложения, которые больше не используются другими карточками. Приложение не отправляет карточки и записи в сеть.

## Локальный голос

Движок speak.js на основе eSpeak и данные включены в исходники. Для воспроизведения файлов из закреплённой версии исходников:

```sh
node scripts/prepare-speech.mjs
```

eSpeak распространяется по GPL-3.0. Лицензия, ссылки на исходники и описание адаптации находятся в `src/voice/LICENSE` и `src/voice/NOTICE` и включаются в HTML-файл. Синтез работает в отдельном Web Worker и не блокирует интерфейс. Вместо большого движка со всеми языками используются компактный движок и полные данные двух языков; текст для русского преобразуется в UTF-8.


## Фразы из фильмов и защита правок

Редактор сохраняет черновик в IndexedDB и спрашивает перед выходом с правками.
После перезагрузки черновик можно открыть с главной. Массовая вставка использует
общий CSV-разбор: таб Quizlet, запятая, точка с запятой, шапка, BOM, кавычки и
многострочные поля. Для дефиса предусмотрен отдельный режим. При неоднозначной
строке выбери первый/последний разделитель или заключи поле в кавычки; проверь
предпросмотр. Повторяющиеся термины можно пропустить или добавить явно.

Кнопка «+» в шапке быстро добавляет карточку в последний набор. У карточек есть
необязательные фильм/сериал, сезон-серия и таймкод; коллекция фильтруется по
источнику. В занятии можно поставить звёздочку и исправить карточку с сохранением
её ID, вложений и прогресса. Есть отдельный режим по звёздочкам.

Горячие клавиши карточек: Пробел — переворот; 1 — ещё повторить; 2 — знаю;
3 — легко; 4 — трудно. Тест по-прежнему принимает цифры 1–4 как варианты ответа.
Лимит новых карточек задаётся в настройках (по умолчанию 20 в день); знакомые
не расходуют лимит. Напоминание работает, пока приложение открыто. Английская
озвучка поддерживает US и UK как в локальном движке, так и у доступных
установленных голосов; примеры можно прослушивать отдельно.

Удалённый набор можно вернуть в течение суток вместе с его расписанием,
точностью и файлами. После окончания срока неиспользуемые вложения очищаются.
JSON-копии версии 1 продолжают читаться. TXT-экспорт Anki включает источники и
тег zhekandus_hard для карточек со звёздочкой; архивы .apkg не возвращены.

## Автокопия и установка на телефон

В «Копиях и импорте» выбери отдельный файл автокопии. Браузеры с File System
Access API записывают туда JSON-копию с прогрессом и вложениями после изменений,
пока приложение открыто. Выбор файла и разрешение на запись делает пользователь. После закрытия или
перезагрузки страницы файл нужно выбрать снова; сохранено только его имя,
а не постоянное разрешение на доступ к файлу.
Если браузер не поддерживает API (в том числе Safari на iPhone), доступна обычная
кнопка «Скачать копию». Ни IndexedDB, ни кэш PWA не заменяют отдельный файл:
очистка данных браузера удаляет оба. Перед сменой устройства перенеси JSON-копию
и восстанови её в другом браузере. Серверной синхронизации нет. При выборе онлайн-голоса браузер может отправлять
текст своему провайдеру; «Живой голос» отправляет текст указанному TTS-провайдеру.
Остальные функции не передают личные карточки в сеть. При ошибке автокопии показывается причина; предыдущий файл не меняется.

`npm run build` создаёт в `dist/` веб-сборку с manifest, PNG-иконками 192/512 и
service worker. Для установки размести содержимое папки `web` из архива на HTTPS
сайте; localhost подходит для разработки. На iPhone: «Поделиться» → «На экран
Домой», на Android: меню браузера → «Установить приложение». Первый запуск
загружает собственные ресурсы сайта, следующие занятия работают из кэша офлайн.
Service worker не отправляет карточки, аудио, картинки или прогресс на сервер.
Самостоятельный `zhekandus.html` продолжает работать без сервера и установки;
браузеры не устанавливают PWA непосредственно из file://.

Приложение распространяется по GNU GPLv3; текст лицензии, уведомления сторонних
компонентов и исходники включены в архив. Сведения и точная ревизия оригинального
движка eSpeak/speak.js сохранены в `src/voice/NOTICE`. Лицензионный комментарий
в начале самостоятельного HTML сохранён.

## Озвучка

В «Настройках → Озвучка слов» выбери режим, акцент US/UK, скорость и нажми
«Проверить озвучку». Под кнопкой останутся **название, язык и тип фактически
запущенного голоса**: онлайн, локальный или запасной. Для каждого доступного
английского системного голоса есть отдельная проверка. Выбор сохраняется.
Автоматический выбор учитывает язык и акцент прежде рейтинга качества;
Natural/Neural/Online/Premium/Enhanced/Google/Samantha/Aria/Jenny выше
compact/eSpeak. Онлайн-голосу даётся 6 секунд на запуск, локальному — 2.
При отсутствии сети доступны сохранённое аудио, Piper, локальные голоса и
последний запасной eSpeak. При переходе на eSpeak появляется ссылка
«Установи нормальный голос» с инструкцией для платформы.

**Живой голос.** Поддержаны OpenAI (`gpt-4o-mini-tts`, например `coral`),
Google Cloud TTS (`en-US-Neural2-F`) и Azure (`en-US-JennyNeural`, регион
своего ресурса). Введи свой ключ, нажми «Сохранить ключ», затем проверь.
Обычные настройки сохраняются сразу. По умолчанию ключ остаётся только в
текущей вкладке; отметка «Запомнить ключ» сохраняет его в отдельной IndexedDB.
Ключ не шифруется, не попадает в данные карточек, JSON-копии или экспорт;
«Забыть API-ключи» удаляет сохранённые ключи. Текст запроса передаётся только
выбранному провайдеру по HTTPS; его тарифы и доступ определяются твоим аккаунтом.
Запрос идёт прямо из браузера без нашего сервера. Если провайдер блокирует
браузерные запросы/CORS, приложение объясняет ошибку и переходит на следующий
доступный голос. Сохранённые записи можно воспроизводить без ключа и интернета.

Облачное/Piper-аудио термина и примера хранится как вложение карточки по её
стабильному ID и включается в **резервную копию версии 1**. Ключ кэша включает
текст, язык/акцент, скорость, провайдера, голос/модель и регион. Повторение
той же записи не создаёт нового запроса. Изменённый текст получает новую запись.

**Piper без интернета.** Выбери Lessac (US) или Alba (UK) и нажми «Скачать и
использовать». Интернет нужен один раз для модели, её конфигурации и WASM
(около 100 МБ; есть прогресс и отмена). Частично загруженные файлы сохраняются,
повторная попытка использует их. Затем новые фразы синтезируются на устройстве
в Web Worker через WASM/ONNX, включая запуск из `file://`. WASM проверяется по
закреплённым SHA-256. Требуются WASM, IndexedDB и достаточно памяти; на слабом
телефоне первая фраза может готовиться дольше. Модели и ключи в резервную копию
не входят, готовое аудио карточек — входит. Очистка данных браузера удалит
модель; её можно скачать повторно. Условия использования конкретной модели
указаны по ссылке в настройках и в скачанном MODEL_CARD.

Полные изменённые функции приведены в [SPEECH-FUNCTIONS.md](docs/SPEECH-FUNCTIONS.md).
Результаты проверки и ограничения: [SPEECH-CHECKS.md](docs/SPEECH-CHECKS.md).
Происхождение и лицензии новых компонентов: `src/voice/PIPER-NOTICE`, `licenses/`.
