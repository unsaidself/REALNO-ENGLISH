# zhekandus

Офлайн-карточки, тесты и интервальное повторение. Интерфейс на русском,
ванильный JavaScript, без бэкенда. В этой версии аудиофункции удалены полностью:
нет озвучки, аудирования, записи произношения, звуковых эффектов, выбора голосов,
облачных TTS, API-ключей и загрузки моделей.

Скачай [zhekandus.zip](./zhekandus.zip), распакуй и открой `zhekandus.html` в
актуальном браузере. Также есть [отдельный HTML](./zhekandus.html). Сервер и
интернет для занятий не нужны. Предпросмотр ZIP в чате не запускает приложение.
Перед заменой старого файла скачай JSON-копию в «Копиях и импорте».

## Карточки

На экране одновременно существует одна сторона карточки. Клик или пробел
меняют текст и подпись «Термин/Значение», а не вращают наложенные 3D-слои.
Короткая анимация учитывает prefers-reduced-motion. Направления «Термин →
значение» и «Значение → термин» поддерживаются во всех соответствующих режимах.
После правки карточки прямо в занятии сохраняется показанная сторона.

Оценки: «Ещё повторить», «Трудно», «Знаю», «Легко». Клавиши: пробел — переворот,
1 — ещё повторить, 2 — знаю, 3 — легко, 4 — трудно. В тесте цифры 1–4 выбирают
вариант ответа. Ошибка снижает уровень повторения на два; «Трудно» сохраняет
его, «Знаю» повышает на один, «Легко» на два. Интервалы: 1, 3, 7, 14, 30, 90 дней.

При каждом запуске порядок вопросов и карточек перемешивается во всех режимах.
Дневной лимит выбирает новые карточки из перемешанной очереди, а редактор
и экспорт сохраняют порядок самого набора. Системы рангов и XP нет.
Серия правильных ответов показана небольшим индикатором в занятии;
его цвет меняется по мере роста. Всплывающего окна винстрика нет.
«Повторить» и «Продолжить» открывают последний выбранный набор. Когда в нём
нет карточек по расписанию, можно выбрать другой режим этого же набора.
Другие темы в очередь не подмешиваются; выбор сохраняется после перезагрузки.

## Возможности

- Свои наборы и категории; новый профиль начинается с пустой коллекции.
- Редактор отдельных полей, стабильные ID, перемещение и удаление карточек,
  массовая вставка Quizlet/CSV с предпросмотром, разделителями и дубликатами.
- Карточки, запоминание, тест, повторение, сопоставление, пропуски,
  слабые карточки и карточки по звёздочкам.
- Печатные ответы принимают варианты через `/`, ведущее `to`, регистр,
  лишние пробелы и одну опечатку для длинных ответов. Есть «Я был прав».
- Источники «фильм/серия/таймкод», поиск по карточкам, фильтр по фильму,
  быстрое добавление, правка из занятия, картинки и примеры использования.
- Ежедневная цель и лимит новых карточек, статистика и серии.
- Настройки сохраняются сразу, есть тёмная тема, фокус-ловушка в модальных
  окнах и режим уменьшения анимаций. На телефоне навигация расположена снизу.
- Черновики и подтверждение выхода, удаление набора с подтверждением и отменой
  в течение суток, отдельный сброс прогресса набора или всего приложения.
- JSON-копии версии 1 с прогрессом и вложениями, CSV/TXT/TSV-импорт,
  CSV и текстовый экспорт Anki. Архивы `.apkg` не поддерживаются.

## Данные и копии

Наборы и прогресс находятся в IndexedDB `zhekandus-media`, а не в самом HTML.
Миграция старого `lexi-data` удаляет localStorage только после успешной записи.
Записи объединяются с задержкой 300 мс и сохраняются при уходе со страницы.
Лимит хранилища объясняется отдельной ошибкой. Напоминание о копии появляется
на главной после 7 дней, а первая запись запрашивает persistent storage.

Старые JSON-копии `zhekandus-backup` версии 1 продолжают читаться. Неизвестные
поля и прежние вложения сохраняются для совместимости, включая старые
аудиофайлы; у них нет проигрывателя или управления в интерфейсе. Только отдельная
база `zhekandus-tts` со скачанными моделями и сохранёнными API-ключами удаляется
при запуске. Основная база карточек и вложений не удаляется. Если старый файл
ещё открыт в другой вкладке, удаление его голосового кэша завершится после её
закрытия. Новый код не обращается к AudioContext, SpeechSynthesis, микрофону
или сетевым TTS-провайдерам.

В браузерах с File System Access API можно выбрать файл автокопии. Он
обновляется после изменений, пока страница открыта. После перезапуска файл
нужно выбрать снова. В Safari и неподдерживаемых браузерах скачивай копии
вручную. Для другого устройства перенеси JSON-копию. Очистка данных браузера
удаляет локальное хранилище; PWA-кэш не заменяет отдельный файл резервной копии.

## Разработка и PWA

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run standalone
```

Node.js 20.19+ или 22.12+; проверено на Node 24. `dist/zhekandus.html` —
самостоятельный HTML с gzip/Base64-загрузчиком. Загрузчик показывает понятную
ошибку, если файл повреждён; старый лицензионный комментарий eSpeak GPLv3
сохранён как историческое уведомление, сам движок удалён.

В `dist/` также создаётся PWA с manifest, иконками 192/512 и service worker.
Папку `web` из архива можно разместить на HTTPS-сайте. Android: меню →
«Установить приложение»; iPhone: «Поделиться» → «На экран Домой». После первого
открытия собственные ресурсы работают из кэша офлайн. PWA из `file://` браузеры
не устанавливают. Напоминания доступны, пока приложение открыто.
После обновления файлов сайта новый worker активируется, когда вся сборка
сохранена в кэше. Перезагрузка страницы загрузит новую версию; занятие
автоматически не прерывается.

Приложение распространяется по GPLv3. Исходники и уведомления лицензий включены
в архив. [Изменения и проверки](docs/CHANGES-2026-10-17.md).
